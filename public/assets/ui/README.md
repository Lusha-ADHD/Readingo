# UI

Assets d’aide visuelle partagés entre les jeux Readingo.

- `tutorial-pointer.png` : main générique pointant vers le haut, utilisée pour
  attirer l’attention sur une carte ou une action disponible.

Le composant `src/components/ui/TutorialPointer.tsx` fournit l’affichage et
l’oscillation verticale, avec une variante immobile lorsque le mouvement réduit
est activé.
